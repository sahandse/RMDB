# RMDB 🎬

مرجع فارسی اطلاعات واقعی فیلم و سریال، بدون کلید API و بدون داده آزمایشی.

## اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کنید. هیچ فایل env یا API key لازم نیست.

## منابع
- [Wikidata](https://www.wikidata.org/) برای فیلم‌ها و برچسب‌های فارسی؛ داده ساختاریافته CC0
- [TVmaze](https://www.tvmaze.com/api) برای سریال‌ها، امتیاز TVmaze و تصاویر؛ CC BY-SA با الزام ذکر منبع و ShareAlike
- تصاویر Wikimedia Commons نیازمند بررسی مجوز هر فایل به‌طور جداگانه‌اند.

## وضعیت
- [x] Next.js + TypeScript + RTL
- [x] صفحه اصلی واکنش‌گرا با دریافت واقعی بدون کلید
- [x] مسیر جایگزین مناسب برای خطای شبکه
- [ ] صفحات جزئیات، جستجو و سینمای ایران
- [ ] پایگاه داده و همگام‌سازی در مقیاس بزرگ
- [ ] بررسی کیفیت تصاویر، مجوزها و تست انتشار

**محدودیت:** بخش فیلم‌ها بر اساس پاسخ Wikidata است و لزوماً تازه‌ترین یا پرطرفدارترین آثار را نشان نمی‌دهد. TVmaze عموماً عنوان فارسی ندارد. نتیجه سرور به‌صورت زنده در این مرحله آزمایش نشده است.
