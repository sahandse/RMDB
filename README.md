# RMDB 🎬
مرجع اطلاعات واقعی فیلم و سریال به زبان فارسی؛ مبتنی بر Next.js و TypeScript.

## اجرا
1. Node.js 20 یا جدیدتر را نصب کنید.
2. `npm install`
3. فایل `.env.example` را با نام `.env.local` کپی کنید.
4. **TMDB_READ_ACCESS_TOKEN** را از حساب TMDB خود وارد کنید.
5. `npm run dev` و سپس http://localhost:3000

## اصول داده
- هیچ فیلم، سریال، پوستر یا امتیاز ساختگی در کد وجود ندارد.
- درخواست‌های اصلی با زبان fa-IR از TMDB دریافت می‌شوند.
- بدون توکن یا هنگام خطای API پیام مناسب نشان داده می‌شود.
- امتیاز نمایشی، امتیاز TMDB است و نباید به اسم IMDb نمایش داده شود.
- استفاده از داده‌های TMDB مشمول شرایط API و الزام درج اعتبار منبع است.
- برای استفاده تجاری، مجوز مناسب TMDB بررسی شود.
